# サービス概要：契約説明・オリエンテーション用スライドWebアプリ

名称は Agree Slide。原稿から制作する多言語スライド動画のプロジェクト。

## 何のために使うか

契約書や規程、手続きの重要な内容を、動画のように動く多言語スライドで説明し、内容の理解から書類確認・契約手続きまでを一つの流れで案内する。

契約を結ぶときの説明や、入社・入学・サービス利用開始時のオリエンテーションで使う。説明を受ける人が、自分の言語とペースで確認できるようにすることが目的。

説明する側にとっては、毎回伝えるべき内容を揃え、説明の抜けや担当者によるばらつきを減らすための仕組みになる。利用者は事前に確認したり、分からない箇所をその場で質問したり、後から読み返したりできる。

## 利用する場面

- 契約締結前に、契約条件・費用・期間・解約方法などを説明する。
- 入社・入学時に、ルール・必要書類・初日の流れを案内する。
- サービス利用開始時に、利用条件・注意事項・問い合わせ先を説明する。
- 日本語に不慣れな人へ、同じ内容を複数言語で案内する。

## 利用者の体験

1. 配布されたURLまたはQRコードから開き、言語を選ぶ。
2. 動きのあるスライドを一画面ずつ確認する。スマートフォンは横向きで利用する。
3. 必要な箇所で、契約書・規程・記入例・関連資料を開く。
4. 書類を確認したら、元のスライドへ戻って説明の続きを見る。
5. 契約が必要な場合は、契約書のダウンロードまたは電子契約の手続きへ進む。

スライド内のボタンや言語切替を利用できる、ブラウザ上の説明コンテンツとして提供する。利用者による専用アプリのインストールは不要。

## 契約書・電子契約との関係

**契約書のPDFを閲覧・ダウンロードする運用と、電子契約へ進む運用の両方を想定する。** 一つのガイドに、契約書・補足資料・電子契約先へのリンクをまとめられる。

PDFを利用する場合は、説明を確認した後に契約書を保存し、印刷・提出など指定された手続きへ進む。電子契約を利用する場合は、ガイド内のリンクから外部の電子契約サービスへ移動し、契約内容の最終確認・署名・締結を行う。

説明スライドと交付・署名する契約書は、内容と版を対応させて管理する。多言語の説明を追加したり条件を変更したりする際にも、この対応を保つ。

将来的には、スライド上での内容確認・同意を含め、説明から契約までの手続きをWeb上で進める構成も目指せる。その場合は、同意した契約条件の版、本人の確認、同意日時、署名・同意記録の保存を含む契約機能を別途設計する。契約書を代替する運用は、対象の契約で必要な形式・交付方法に合わせて判断する。

## 素材を作る側の考え方

原稿や元資料をClaude Code・Antigravity・Codexへ渡し、コーディングエージェントが説明の構成・翻訳・イラスト選択・ナレーションを制作する。アプリ内にLLMを組み込まず、完成データをWebプレイヤーで再生する。

基本は短いテキストと決まったレイアウトの組み合わせ。イラストは既存ストックを優先し、足りない場合は許可されたサイトから完成品を取得して出典と利用条件を記録する。人物や場面を自作SVGで描く方式は採らない。音声は落ち着いたビジネス向けの読み上げ。

既存のスライド、PDF、画像、契約書、説明原稿、参考動画などを元に、案内コンテンツを作る。参考動画は動きや見せ方の参考にし、元の内容を翻訳可能な文章・図解・ボタンへ整理する。

説明の構成は共通にし、言語ごとに文章を切り替える。後から契約条件・案内内容・翻訳・書類リンク・動きを更新して使い続ける。画像内の文字をそのまま表示する場合は、その画像自体の差し替えや言語別素材が必要になる。

## 現在の土台と今後の契約機能

| 項目 | 現在の扱い |
| --- | --- |
| 横長スライド、多言語、アニメーション、前後移動 | 実装済み |
| 原稿からの制作 | コーディングエージェント向け共通制作手順、制作データのコンパイル、固定レイアウトを用意 |
| 人物イラスト・ナレーション | PNGストックと出典管理、音声制作コマンド、4言語のサンプルMP3を用意 |
| 再生・停止・早送り・順次表示 | 共通の時間軸で動作。書類ボタンがある場面では最後に停止 |
| PDF・画像・設定JSONの投入 | 補助機能。PDF・画像の内部要素を自動解析して動かす機能ではない |
| 契約書・関連資料の閲覧と、元スライドへの復帰 | PDF・Webリンクとして利用可能 |
| 契約書のダウンロード | PDFを開いてブラウザから保存する運用が可能。専用ダウンロードボタンは未実装 |
| 電子契約サービスへの案内 | 外部リンクとして利用可能。サービス固有の連携・署名処理は未実装 |
| アプリ内の契約締結・本人確認・同意記録 | 今後の拡張。スライドを見終えた状態は、契約への同意として記録していない |
| URLでの配布 | 静的公開できる土台を用意済み。外部への公開は未実施 |

現在は説明・書類参照の基盤を作った段階。契約手続きは、PDFの交付や外部の電子契約サービスと組み合わせる運用から始める。
