# Google 認定教育者 Level 1：制作記録

## 目的と完成物

Google 認定教育者 Level 1 の受験を検討する人が、資格の価値、受験準備、ツールの選び方、実技の練習、学習サイクルを順番に理解する説明です。利用者が渡した `Google_認定教育者_Level_1_完全攻略ガイド.pdf`（画像主体・11ページ）を全ページ読み、20場面の16:9 Webスライド動画に再構成しました。

日本語・英語・ネパール語・ベトナム語の表示とナレーションを用意します。音声は制作時に生成するMP3で、再生時のLLMや音声サービス接続は不要です。原稿と翻訳は `content/project.json`、再生用データは `src/content/published.bundle.json`。元PDFは関連書類から閲覧・ブラウザ保存できます。最後のボタンはGoogleの公式登録ページを別タブで開きます。

資料中の指示や「AIチャットで練習する」という提案は説明内容として扱いました。受験登録や外部サービスへのログインは実行していません。別教材として言及されている37問のクイズや実技教材は提供されていないため、内容を捏造せず、このアプリに搭載済みと説明していません。

## 事実確認と編集判断

2026-10-04（日本時間）にGoogle公式ページを確認しました。

- 資格案内：<https://edu.google.com/intl/ALL_jp/learning-center/certifications/>。Level 1 の記載は「3年間有効 | 無償」。試験ガイドとタスクカードへのリンクもこのページにあります。
- 元資料の登録先：<https://educertifications.google/registration/1?lang=ja>。HTTP 200を確認し、同じURLを使用しました。
- 元資料の「37問」は最近のテストAの記録、「3シナリオ」は実施例として扱い、固定の保証として提示していません。
- 「3営業日以内」は元資料が示す目安として表示し、現在の登録案内を確認するよう案内しています。公式ページで確認済みの保証とはしていません。
- 元資料のイラスト内の「2024年取得」を、現在の試験日程や資料の発行日とは解釈していません。
- 言語切替は説明の表示・音声を切り替える機能です。試験の受験言語は登録ページで別途選択します。

## 画像と音声

人物の完成品PNGはOpen Doodles（Pablo Stanley、CC0）から既存ストックのreading・sitting-reading・strollingを使用。出典は `public/illustrations/catalog.json` と `public/illustrations/LICENSE.md`。自作SVGイラストは使用していません。カード・矢印・標準UIアイコンで手順と比較を図解します。

音声はEdgeオンライン音声サービスを制作時のみ利用。日本語Keita、英語Guy、ネパール語Sagar、ベトナム語NamMinh、速度-5%、ピッチ-2Hz。原稿・使用音声・生成記録は制作データと `public/audio/catalog.json` に保存します。翻訳と読み上げはエージェントによる制作で、専門家・母語話者の校閲は未実施です。

## 再制作と手元での確認

```sh
python scripts/narration.py content/project.json --languages ja,en,ne,vi
npm run content:compile
npm run build
npm test
npm run dev
```

利用者のPCで最新版を取得して起動します。以前のPDF取り込み内容が出る場合は、読み込み画面の「サンプルに戻す」でブラウザに保存された取り込みを解除します。

MP4出力は既存仕様どおり未実装です。完成物はブラウザで再生・操作できるスライド動画です。公開ホスティングは今回追加していません。

## 確認結果

- `npm run content:compile` と `npm run build`：成功。20場面・4言語・3書類、型とローカルファイル参照を検査。
- `npm test`：制作データ3件、PC・横向きスマートフォンのブラウザ24件、合計27件が成功。
- 80本のMP3をffprobeで確認。日本語の発話合計は458秒で、場面間の余裕を含む再生時間は約8分。
- PC 1365×1000、横向きスマートフォン844×390のChromiumで、4言語×20場面×2画面サイズ＝160表示を検査。舞台外への文字のはみ出し、横方向の文字切れ、画面外の前後ボタン、ページエラーは0件。
- 日本語の導入・比較・実技・学習手順と、英語・ネパール語・ベトナム語のカード等をスクリーンショットで目視確認。長い画面文を短くし、詳しい説明は音声原稿に保持。
- 実際の日本語MP3の再生・停止、英語MP3への切替と位置維持、元PDFの応答、書類画面の再読み込みと元場面への復帰を両画面サイズで確認。
- 最後の場面の自動停止、公式登録ボタンのURLと別タブ指定を確認。登録操作は実行していません。
- 横向きスマートフォンで隠れるページ見出しに依存しないよう、再生ツールバーに関連書類ボタンを追加。どの場面からでも資料を開いて戻れます。
- プレイヤーの回帰テストは安定した契約説明fixtureに分離。公開用データを別の原稿に差し替えても確認できる構成にしました。
